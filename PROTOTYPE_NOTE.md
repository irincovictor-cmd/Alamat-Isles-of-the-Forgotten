# Playable prototype location

The full playable client is `alamat-prototype.html` (also intended as `index.html` for GitHub Pages).

**Gameplay works offline** — open the HTML file in any modern browser. No Django required to play.

If `alamat-prototype.html` is not yet in this repo, copy it from your download/session artifacts, then:

```bash
git add alamat-prototype.html index.html
git commit -m "Add playable HTML prototype"
git push
```

Controls: Arrows/WASD move, E/Space interact, P party, F5 save, F9 load.

See **PROGRESS.md** for the full session summary.
